How it works
  • Passwords are collected from cracked tasks and cached key files.
  • Duplicates are removed while keeping the newest discoveries first.
  • For each target ESSID, the server precomputes WPA PMKs from this list.
  • PMK Cache mode checks those PMKs with hashcat mode 22001.
